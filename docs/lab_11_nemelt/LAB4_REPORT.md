# LAB 4 — Нэгжийн тестлэл ба TDD

**Огноо:** 2026-11-23
**Төсөл:** Our-New-Web-App
**Тестийн хэрэгсэл:** Vitest
**Програмчлалын хэл:** TypeScript

## 1. Зорилго

Бүртгэлийн өгөгдөл шалгах функцүүдийн зөв ажиллагааг нэгж тестээр баталгаажуулах.

## 2. Ашигласан технологи

- TypeScript
- Vitest
- Node.js
- npm

## 3. Тестэлсэн хэсгүүд

- Хэрэглэгчийн нэрийн шалгалт.
- И-мэйл болон утасны дугаарын формат.
- Нууц үгийн уртын шалгалт.
- Буруу өгөгдлийн алдааны мэдээлэл.
- Эерэг болон сөрөг тестүүд.

## 4. Нэмсэн хилийн утгын тестүүд

1. Нэр яг 100 тэмдэгт байхад зөвшөөрөх.
2. Нууц үг яг 200 тэмдэгт байхад зөвшөөрөх.
3. И-мэйл яг 254 тэмдэгт байхад зөвшөөрөх.
4. И-мэйл 255 тэмдэгт байхад татгалзах.

## 5. Тестийн үр дүн

`npm test`:

- Тестийн файл: 8 passed.
- Нийт тест: 187 passed.
- Амжилтгүй тест: 0.

`npm run typecheck`:

- TypeScript шалгалт амжилттай.
- Алдаа илрээгүй.

## 6. Анхаарах зүйл

Тест ажиллах үед DATABASE_URL тохируулаагүй гэсэн анхааруулга гарсан. Иймээс бодит өгөгдлийн сантай бүртгэл хийх ажиллагааг баталгаажуулаагүй.

## 7. Дүгнэлт

Backend-ийн 8 тестийн файл дахь 187 тест амжилттай ажилласан. Бүртгэлийн validation-ийн хилийн утгуудыг шалгасан бөгөөд TypeScript шалгалтаар алдаа илрээгүй.
